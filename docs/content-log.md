# Content log — themes

Tracks **content**. `STATUS.md` tracks **code**; the two move at different speeds and a theme
being drafted for a month is not a stalled project.

One row per theme, including ones that are only an idea. Update it in the same commit that
adds, drafts or publishes a theme.

**Status values**

| Status | Meaning |
|---|---|
| `idea` | A label and a hunch. No file in `content/themes/` yet. |
| `drafted` | File exists, `published: false`. Verses may be provisional. |
| `published` | `published: true` — live at `/theme/{slug}/`, and a claim that it meets the editorial standard in [`theme-prd.md`](./theme-prd.md#10-editorial-standard--what-makes-a-theme-publishable). |

A published theme is a permanent URL. Read section 6 of `theme-prd.md` before choosing a slug.
